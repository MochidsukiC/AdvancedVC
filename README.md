# Advanced VC (Advanced Voice Chat)

高度音響VCシステム - Minecraft Forge 1.20.1用の包括的な音声通信MOD

## 概要

Advanced VCは、Minecraftでのボイスチャット体験を革新する、Simple Voice Chat (SVC)に依存しない独自の音声通信システムです。物理法則に基づく音響シミュレーション、ウォーキートーキー、低遅延音楽セッションの3つの主要モードを提供します。

## 主な機能

### 🎙️ 3つの音声通信モード

1. **シミュレーションモード（デフォルト）**
   - 物理法則ベースの音響シミュレーション
   - 距離減衰、ブロックによる音の伝播
   - 音声アクティビティ検出（VAD）で自動起動
   - デバイスモードと同時使用可能

2. **デバイス通信モード（ウォーキートーキー）**
   - 距離無制限のグループチャット
   - 周波数設定による通信グループ管理
   - プッシュトゥトーク（PTT）方式
   - 特有の音質劣化エフェクト

3. **バンドモード（低遅延）**
   - リアルタイム音楽セッション用
   - 目標遅延: 25-40ms
   - 指揮者ベースの同期システム（実装予定）

### 🔊 5段階の声量設定

- **独り言** (5m)
- **囁き** (10m)
- **会話** (30m) - デフォルト
- **演説** (60m)
- **叫び** (100m)

キーバインド（テンキー+/-）で簡単に切り替え可能

### 🧱 音響ブロック

- **マイクロフォンブロック**: 範囲内のプレイヤーの音声を拾う
- **スピーカーブロック**: 音声を増幅して再生
- **防音材**: 音を完全に遮断（吸収率1.0）
- **吸音材**: 音の反射を防ぐ（反射率0.0）

### 📻 アイテム

- **ウォーキートーキー**: 周波数設定可能な通信デバイス（1-999）
- **バンドツール**: PAミキサー機能（実装予定）

## 技術仕様

### アーキテクチャ

```
クライアント:
- マイク入力 → VAD → Opusエンコード → UDP送信
- UDP受信 → Opusデコード → 音響処理 → 3D/2D再生

サーバー:
- UDP受信 → ルーティング → UDP送信
- 距離/周波数ベースのフィルタリング
```

### 使用技術

- **Opus Codec**: 高品質/低遅延音声エンコーディング（Concentusライブラリ）
- **Java Sound API**: マイク入力・オーディオ再生
- **独自UDP通信**: Minecraftのネットワークから分離した低遅延通信
- **Forge Network Channel**: 制御データの信頼性の高い送信

### パフォーマンス最適化

- **クライアントサイド音響計算**: サーバー負荷を大幅削減（O(N²) → O(N×K)）
- **音声アクティビティ検出**: 無音時のパケット送信を抑制
- **ジッターバッファ**: ネットワーク遅延の変動を吸収

## キー操作

| キー | 機能 |
|------|------|
| V | プッシュトゥトーク（PTT） |
| M | ミュート/ミュート解除 |
| テンキー+ | 声量アップ |
| テンキー- | 声量ダウン |

*キー設定は変更可能*

## 設定

`config/advancedvc-common.toml`で以下を設定可能:

- UDPポート（デフォルト: 24455）
- サンプルレート（デフォルト: 48kHz）
- Opusビットレート（高品質: 64kbps、低品質: 8kbps）
- VAD閾値
- 距離減衰係数
- ボイスチャット有効/無効
- 自動起動設定

## API for Mod Developers

他MODとの連携をサポートするAPIを提供:

```java
// 音響特性の登録
AdvancedProximityChatAPI.getInstance()
    .registerSoundOcclusionBlock(myBlock, 0.8f, 0.2f);

// カスタムストリームフィルターの適用
StreamFilterParameters params = new StreamFilterParameters()
    .lowCut(300)
    .highCut(3400)
    .bitrate(8000);

api.applyCustomStreamFilter("phone_filter", sender, receiver, params);
```
